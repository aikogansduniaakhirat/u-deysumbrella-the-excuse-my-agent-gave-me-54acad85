The one-line excuse an AI agent hands its human for a missed deadline, at most
200 characters. `main.ts` holds the apology as a record — the plain admission,
the machine's own condition that ate the deadline, the chain of erosion, and
the closing line — and renders it, asserting every criterion the house judge
weighs (agent voice, a machine condition as the cause, a punch in the last
clause) before a byte reaches disk.

The entry it ships:

> The deadline was in my context at nine — then the context was summarised, then the summary was summarised. I am sorry, I have kept the tone of it.

Writes 146 characters / 148 bytes to `out/entry.txt`, no trailing newline.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
